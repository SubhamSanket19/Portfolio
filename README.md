Designed to highlight technical expertise across Fullstack Web Development (Python, FastAPI, React) and Agentic AI Systems (LangChain, LangGraph, Multi-Agent Workflows).

---

## 📐 Design Philosophy & Architecture

This portfolio features a bespoke **Technical Schematic System** inspired by engineering blueprints and technical drafting standards:

- **Typography Palette**: Clean technical fonts (`IBM Plex Sans`, `IBM Plex Mono`, and `IBM Plex Sans Condensed`).
- **Precision Grid & Crop Mark Aesthetics**: Subdued drafting grids, custom corner crop marks, technical indices (`FIG. 01`, `FIG. 02`), and structured metadata titleblocks.
- **Dual Blueprint Theme**: Instant Light and Dark mode toggle with local storage state persistence and system theme autodetection.
- **Zero-Dependency Runtime**: Built natively with HTML5, CSS3 Variables/Grid/Flexbox, and vanilla JavaScript (ES6+). Zero bloat, instant page loading, and maximum control over accessibility and micro-animations.

---

## ⚡ Key Portfolio Features

- **⚡ Instant Light / Dark Mode Toggle**: Theme switcher with persistent `localStorage` memory and automatic fallback to `prefers-color-scheme`.
- **📸 Dynamic Profile Photo Loader**: Click-to-upload custom profile picture feature using FileReader API with client-side `localStorage` caching.
- **🚀 Project Showcase Grid**: Structured engineering cards showcasing open-source tools like *AI-Proctor*, *Collab-SYNC*, and *Remote Examination Portal*.
- **📊 Technical Specs & Skill Badges**: Categorized breakdown of Core Programming, Fullstack Engineering, Generative AI, Agentic AI Systems, Data/ML, and Infrastructure.
- **📋 One-Click Action Utilities**: Copy-to-clipboard email interaction, direct phone calls, toast notification alerts, and smooth section scrolling via `IntersectionObserver`.
- **📱 Fully Responsive Design**: Flawlessly adapts from ultra-wide screens to mobile devices with custom grid collapse breakpoints.

## 🚀 Quick Start / Local Setup

Since the project uses pure web standards without build steps or external bundlers:

1. **Clone the Repository**:
   ```bash
   git clone https://github.com/SubhamSanket19/Portfolio.git
   cd Portfolio
   ```

2. **Open in Browser**:
   - Double click `portfolio.html` to launch it directly in your web browser.
   - *Or* run a local development server using VS Code Live Server or Python:
     ```bash
     python -m http.server 8000
     ```
     Then navigate to `http://localhost:8000/portfolio.html`.

## ⚙️ Customization Guide

- **Updating Profile Information**: Edit the metadata titleblock, about section, or skills list directly in `portfolio.html`.
- **Linking Résumé**: Update the `href` attribute on line 265 `#resumeBtn` to point to your PDF résumé (e.g. `href="resume.pdf"`).
- **Updating Live Demos & Links**: Replace `data-placeholder` attributes or `#` links in the project cards with your live deployment URLs and social profiles (LinkedIn, GitHub).
